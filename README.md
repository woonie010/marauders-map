# Marauder's Map

A team project developed at Monash University.

Marauder's Map is a 3D tracking and visualization web application that uses camera-based location data to visualize user movement within an interactive virtual environment.

## My Contributions

- Developed interactive 3D environments using React and Three.js
- Implemented multi-floor navigation and exploration
- Built dynamic JSON-based coordinate rendering for location visualization
- Integrated the React frontend with the Flask backend
- Integrated MongoDB for location and related data management
- Integrated Blender 3D assets into the Three.js environment

## Tech Stack

- React
- TypeScript / JavaScript
- Three.js
- Blender
- Flask
- MongoDB

## Project Context

This project was originally developed as a team project at Monash University.  
This repository is a portfolio copy showcasing the project and my individual contributions.
